# Smart Gym website

Hostinger-ready PHP website for a gym client website + LynxCom data collection direction.

Files:
- index.php: public website with service/pricing/content
- submit-member.php: member registration data capture
- thank-you.php: noindex post-submit page
- assets/styles.css: responsive design
- assets/script.js: mobile navigation
- data/member-registrations.csv: created automatically after form submissions

This is a website package. Replace sample prices, trainers, address, phone, email, images and exact client offer before production deployment.
