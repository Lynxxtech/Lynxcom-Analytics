# Crestfield Model Academy — School Web Dashboard Demo

This is a privacy-safe LynxCom Analytics sample project.

## What this demonstrates
- Excel/structured data as the backend source
- Client-facing web dashboard as the presentable deliverable
- Parent debtors/follow-up action list
- Fee collection review
- Admissions pipeline
- Boarding overview
- Expense summary
- Future update workflow

## How to run locally
```bash
cd /root/lynxcom_sample_projects/school_web_dashboard
python3 -m http.server 8095
```
Then open: http://127.0.0.1:8095

## Privacy
All data is dummy data. No real school, student, parent or financial records are included.
